# UM982 / WitMotion Reference Material

Drop datasheets, protocol manuals, and command references here. Suggested
layout:

- `datasheet/` - UM982 chip datasheet (Unicore).
- `manual/` - WitMotion module user manual / quick-start.
- `protocol/` - NMEA + Unicore binary command/message reference.
- `wiring/` - pinouts, connector diagrams, antenna layout notes.

These files are reference-only and are **not** installed by the package.
